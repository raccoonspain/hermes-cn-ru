Дизайн веб-морды Hermes

Полный путь пользователя — 5 страниц

login.html — вход: выбор профиля (dem / Глеб) + пароль, на фоне анимированное созвездие.

home.html — главная после входа: плитки навигации (работа с проектами, быстрый чат, поиск везде, админка — только для владельца), переключатель роли для демонстрации, кнопка выхода.

project-selector.html — селектор проектов (Группы слева с поиском/закреплением/эмодзи/редактированием, Проекты справа с RAG-поиском/тегами/статусом/регулировкой размера плиток, слайд-панель about.md). Интерактивно — можно реально кликать.

project-workspace.html — рабочее окно проекта: дерево файлов слева (source/outer/result цветом), чат в центре (Markdown-рендер + копирование, вставка картинки из буфера — Ctrl+V, вложения реально скачиваются), техническая область справа (лог агента / хронология файлов со скроллом к сообщению).

admin.html — страница администратора: пользователи, метрики VPS/wormsoft.ru (CPU/RAM/диск, кредиты, rate limit), журнал.

Черновики — 4 направления (для истории)

Один и тот же набор условных данных (пространство «dem»: ALL + 3 группы, 8 карточек проектов) — четыре разных визуальных направления, из которых выбран вариант 2.

1 · «Картотека»

variant-1-kartoteka.html

Бумажная картотека/архив: папки-вкладки по группам, карточки с перфорацией и «печатью» статуса (актив/архив), моноширинные метки как в каталожной карточке.

2 · «Созвездие»

variant-2-sozvezdie.html

Тёмная карта знаний в духе графа Obsidian (на который вы сами ссылались) — глубокий индиго, звёзды вместо статусов, тёплое золото вместо неона.

3 · «Пульт»

variant-3-pult.html

Светлый терминал: моноширинный шрифт, ASCII-дерево (├──/└──) как в выводе ls, статус — в квадратных скобках. Отсылка к тому, что Hermes — это CLI-агент.

4 · «Тетрадь»

variant-4-tetrad.html

Тёплая линованная тетрадь с цветными вкладками-разделителями по группам и красной полосой на полях — по духу ближе к семейному/ учебному использованию (вы сами упоминали сына и «Блок знаний»).

Данные во всех вариантах — условные, для оценки дизайна, не реальные проекты.
