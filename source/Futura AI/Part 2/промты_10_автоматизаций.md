# 10 автоматизаций "Chief of Staff" для Hermes Agent
# Каждая -- крон-задача. Скопируй промт и отправь Hermes в чат.

---

## 1. Утренний брифинг
**Крон:** каждый день в 8:00

```
Каждый день в 8 утра собери утренний брифинг и пришли в Telegram:
- Мой календарь на сегодня (через Composio CLI)
- Непрочитанные важные письма (через Composio CLI Gmail)
- Задачи на сегодня из последнего вечернего отчета
- Состояние сервера: диск, память, аптайм
Формат: короткий, без воды, списком.
```

---

## 2. Трекинг контента
**Крон:** каждый понедельник в 9:00

```
Каждый понедельник в 9 утра проанализируй мой контент за прошлую неделю:
- Какие посты/видео зашли (просмотры, лайки, комменты)
- Какие не зашли
- Паттерны: что работает, что нет
- 3 рекомендации на эту неделю
Данные бери из [указать источник: YouTube Analytics, Telegram-канал].
Пришли в Telegram.
```

## 3. Трендовый радар
**Крон:** каждые 6 часов

```
Каждые 6 часов проверяй тренды в моей нише [указать нишу]:
- Новые инструменты и продукты
- Вирусные посты в X/Twitter (через SuperGrok x_search)
- Обсуждения на Reddit и HackerNews
Если нашел что-то стоящее -- пришли сразу в Telegram с пометкой ТРЕНД.
Если ничего нового -- не присылай ничего.
```

## 4. Подготовка к встречам
**Крон:** за 1 час до каждой встречи (проверка календаря)

```
За час до каждой встречи в моем календаре подготовь краткое досье:
- Кто участник (имя, компания, должность)
- Чем занимается (из открытых источников)
- Последние публикации/новости о нем
- О чем может пойти разговор
- 2-3 вопроса, которые стоит задать
Пришли в Telegram.
```

## 5. Humanizer (аудит текста на AI-паттерны)
**Не крон, а навык.** Вызывается по запросу.

```
Проверь этот текст на AI-паттерны:
- "Конечно!", "Стоит отметить", "В заключение", "Ключевой"
- Одинаковая длина предложений
- Списки из трех пунктов подряд
- "Не просто X, а Y"
- Лишние вступления и заключения
- Чрезмерное использование тире

Перепиши так, чтобы звучало как живой человек. Сохрани смысл.
Покажи: оригинал, что нашел, переписанный вариант.
```

## 6. Обработка закладок
**Крон:** каждый вечер в 22:00

```
Каждый вечер в 22:00 проверь мои новые закладки:
- Telegram сохраненные сообщения
- [Другие источники если есть]
Для каждой закладки:
- Кратко: о чем (1-2 предложения)
- Категория (инструменты / идеи / статьи / контакты)
- Сохрани в Obsidian в папку /bookmarks/[категория]/
Пришли мне итог: сколько обработано, какие категории.
```

## 7. Категоризация саппорта
**Крон:** каждые 2 часа

```
Каждые 2 часа проверяй входящие обращения в [Telegram-бот / почту]:
- Рассортируй по категориям: вопрос / проблема / запрос функции / спам
- Присвой приоритет: высокий / средний / низкий
- Высокий приоритет -- пришли мне сразу в Telegram
- Средний и низкий -- собери в отчет к утру
Не отвечай клиентам сам. Только сортируй и уведомляй меня.
```

## 8. Еженедельный дашборд
**Крон:** каждую пятницу в 18:00

```
Каждую пятницу в 18:00 собери еженедельный отчет:
- Ключевые метрики: [подписчики / выручка / лиды / конверсия]
- Сравнение с прошлой неделей (рост/падение)
- Что сделано за неделю (из истории наших разговоров)
- Что осталось незакрытым
- 3 приоритета на следующую неделю
Формат: markdown, с цифрами. Пришли в Telegram.
```

## 9. Obsidian Daily Notes
**Крон:** каждый день в 23:40

```
Каждый день в 23:40 напиши итог дня в Obsidian:
- Файл: /daily/[дата в формате YYYY-MM-DD].md
- Что обсуждали сегодня (из истории разговоров)
- Какие решения приняты
- Какие задачи поставлены и кому
- Что осталось незакрытым
- Мои мысли/идеи которые прозвучали
Не присылай в Telegram, просто сохрани в Obsidian.
```

## 10. NotebookLM -- бесплатная библиотека Google
**Крон:** каждый день в 8:00

```
Каждое утро в 8:00 загляни в мою библиотеку NotebookLM.
Найди что-то полезное по теме [указать нишу] на основе наших разговоров за последние сутки.
Создай краткую подборку и скинь инфографику в Telegram.
```

Что нужно: установить NotebookLM skill (community), залогиниться в NotebookLM через браузер.
Бесплатный тир: до 50 источников на один ноутбук. Платный (Pro): до 300.

## Советы по кронам

- **Ночные задачи** (аналитика, отчеты, обработка данных): ставьте на 3:00. Утром все готово.
- **Утренний брифинг**: 8:00 (или когда просыпаетесь).
- **Вечерний итог**: 23:40 (перед сном).
- **Мониторинг** (тренды, саппорт): каждые 2-6 часов.
- **Еженедельные отчеты**: пятница 18:00.
