## Бесплатные файлы (в Telegram-канале)

1. **Шаблон SOUL.md** -- готовый шаблон личности агента (Identity, Mission, Business, Voice, Rules + метод brain dump)
2. **docker-compose.yml** -- конфигурация для запуска Hermes в Docker
3. **env_template.txt** -- шаблон .env с переменными для всех провайдеров
4. **Промты для 10 автоматизаций** -- готовые промты для всех крон-задач "Chief of Staff"
5. **Промт для Codex (Docker)** -- 12-шаговый промт, который разворачивает весь Hermes в Docker через Codex
6. **PDF-гайд** -- обновленный полный гайд со всеми командами
7. **hooks_template.yaml** -- шаблон хуков безопасности (4 готовых хука + Python-скрипты: блокировка rm, защита .env, аудит-лог, инжекция контекста)
8. **Telegram-команды** -- все 12 команд из видео одним файлом (копируй и отправляй боту)

### Безопасность и настройка (команды из видео)
- Компрессия: `hermes config set compression.threshold 0.80`
- Терминал: `hermes config set terminal.backend docker`
- API-ключ (безопасно): `hermes config set providers.anthropic.api_key YOUR_KEY`
- Telegram ID: `hermes config set telegram.allowed_users YOUR_ID`
- Проверка модели: `hermes config get model`
- Узнать свой Telegram ID: @userinfobot в Telegram
- Kawaii-режим: kawaii: true → false в config.yaml
- API-ключи протухают молча -- проверяйте раз в месяц
- SOUL.md правило: "Не отправляй письма сам -- только черновик"
- Fallback-модель: providers.fallback в config.yaml
- Бэкап: ~/.hermes → приватный GitHub-репозиторий

### Контроль и защита (новое в 2.0)
- `hermes doctor` -- CLI-диагностика одной командой (0 токенов, shell + SQL). В Telegram: «Запусти диагностику»
- Shell Hooks -- перехват действий агента ДО выполнения (файл `hooks.yaml`)
  - Настройка через Telegram: "Создай хук безопасности: блокируй удаление за пределами рабочей папки"
  - Или вручную: файл `hooks.yaml` рядом с агентом
  - Три основных типа (из 15+): `pre_tool_call`, `post_tool_call`, `pre_llm_call`
- No-agent jobs -- крон-задачи без LLM (флаг `no_agent: true`)
  - Бэкап, проверка диска, чистка логов -- 0 токенов
- Параллельная делегация -- N задач одновременно
  - Настройка через Telegram: "Включи параллельную делегацию, максимум 3 процесса"
  - Или в config.yaml: `delegation.max_concurrent_children: 3`, `delegation.max_spawn_depth: 1`
  - Нюанс: 3 процесса = 3x расход токенов, используйте с дешевой моделью (DeepSeek)

### OpenRouter (один ключ на все модели)
- Сайт: openrouter.ai
- BYOK (Bring Your Own Key): вставьте свой DeepSeek-ключ в OpenRouter -- без наценки, обход rate limits
- Nitro: автовыбор быстрейшего провайдера
- Fallbacks: автопереключение при падении провайдера
- Zero completion: не платите за пустые/ошибочные ответы
- Подключение: `hermes setup model` → выбрать OpenRouter

### Codex -- установка, ремонт, аудит
- Codex: openai.com/codex -- входит в ChatGPT Plus ($20/мес) и Pro ($200/мес)
- Установка Hermes в Docker: промт из 12 шагов (в Telegram-канале)
- Ремонт: "Мой Hermes Agent не работает, почини"
- Аудит: "Проверь мою конфигурацию Hermes Agent. Безопасность, оптимальность, что можно улучшить"
