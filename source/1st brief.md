# Драфт первого брифа проекта

## Цели проекта

Получить рабочую версию hermes агента со следующими условиями и ограничениями:
1. Агент будет крутиться на VPS в ру зоне, чтобы не мешали блокировки РКН и иметь доступ к агенту без VPN
2. По причинам, опирающимся на п.1 доступ к агенту через чат должен быть через matrix а не телеграм, как везде делают
2.1 У меня поднят свой собственный matrix сервер на домашнем сервере со статичным ip и доменным именем, я могу создавать там учетные записи для пользователей и переписываться через element на телефоне и пк
3. Должна быть возможность общения с агентом через веб морду, на случай, если я буду работать за чужим комьютером, где нельзя установить element, а чтобы запустить matrix web нужен VPN
4. Чтобы не было проблем с доступом к языковым моделям не в ру зоне, у меня есть подписка на поставщика моделей в ру зоне, но он поставляет исключительно китайские модели

## Что должен уметь агент и что я с помощью него хочу делать

- Инструменты, которыми агент (в том числе с помощью ИИ моделей) должен уметь пользоваться
    - должен уметь понимать изображения, т.е. сбросив ему скриншот в чат, агент должен понять что на этом изображении
    - должен уметь транскрибировать, если я сброшу ссылку на youtube или другой видео хостинг, или выложу на VPS ему в папку видео, должнен уметь транскрибировать видео + чтобы я мог в чат говорить аудио сообщение, а агент понимал, что требуется
    - должен уместь работать с нередакрируемыми файлами pdf и редактируемыми word, excel, dxf в обе стороны - то есть из pdf делать редактируемый word / excel / dxf, и наоборот генерировать word / excel / dxf и конвертировать в pdf
    - должен уметь искать в интернете, у меня есть подписка на perplexity, нужно подключить ее на поиск, чтобы агент мог ей пользоваться

- Роль помощника по изучению какой-то либо темы. Блок знаний.
    - Я говорю, что нужно завести тему для изучения
    - Агент создает под эту тему у себя проект
    - Я сбрасываю ему имеющийся у меня контекст по теме (учебники, видео лекции).
        - Или прошу поискать информацию в интеренете
    - Агент собирает конспект для меня
    - Делает html программу с тестами и задачами, чтобы я смог проверить свой уровень понимания тему
    - Я сбрасываю задачники. Говорю номера задач. Агент делает мне подробный разбор задач в html с текстом и изображениями (графики, векторы, какие-то примеры)
    - Агент собирает темы в какой-то удобный индекс, чтобы можено было запросить весь список тем и посмотреть, что мы изучили + чтобы не плодить новые темы, если были уже ранее похожие темы - агент сам понимает, что нужно создать новую тему или использовать ранее проработанную с имеющимся проработанным контекстом

- Роль ассистента по какой либо теме. Блок поиска
    - Я задаю тему / интересующий меня вопрос. Говорю, что нужно поискать в интернете
    - Агент через перплексити ищет ответ на мой вопрос
    - Мы продолжаем общаться по этой теме. Агент пользуется поиском и подключенными моделями.
    - В процессе работы он генерирует мне документы / схемы / таблицы в нужном мне формате
    - Если я хочу закрепить эту тему в Блоке знаний, чтобы потом вернуться к теме и развивать, я говорю об этом, и это попадает в Блок знаний

- Роль IT ассистента. Блок разработки
    - Это резервный канал для написания программ и поддерживания цифровой и сетевой инфраструктуры. В условиях, когда нет возможности дать доступ Claude Code или Codex к файлам - переписка с агентом для решения текущих задач
    - Буду так же просить создавать темы в Блоке разработки (под каждую тему будет создаваться свой проект), чтобы потом можо было вернуться к любой теме.
    - Так же под блок разработки должен собираться архив уже изученных знаний, грабель, правил, туда закачивать документацию по средам программирования и правилам оперделенных сервисов, чтобы ускорять поиск решений и не повторять из разработки к разработке один и те же ошибки. Возможно даже готовить библиотеку шаблонов.
    - Я буду сбрасывать вопросы, куски кода, возможно целые файлы
    - Агент с помощью подключенных моделей писать / исправлять / анализировать код
        -  Помимо распространенных языков python, java script, php, SQL и т.п. что используется повсеместно, нужно еще понимать структуру / архитектуру 1С (бухгалтерия и управление предприятием, зарплата и управление персоналом) уметь подсказать как построить проект, написать / проверить код
    - Уметь решать вопросы с сетевой инфраструкторой в том числе поднятием и обслуживанием VPN / прокси серверов

- У меня есть поднятые серверы VPN, нужно, чтобы агент мог использовать VPN, чтобы работать с видео по ссылкам из youtube
