# Пост

## Основной блок
Hermes + GPT 5.6 Sol — оптимальный стек для документооборота, исследований и автоматизации бизнес-процессов с правильной архитектурой управления. На основе опыта. 

✅ ИДЕАЛЬНО ПОДХОДИТ:

🔸 Архиватор документов  
└ Сканирование → обработка → структурирование → быстрый поиск и Q&A

🔸 Глубокий исследователь  
└ Параллельные цепочки рассуждений, поиск сути, построение аналитики

🔸 Документ-ассистент  
└ Претензии, заявления, обращения — поиск правильной структуры + отправка

🔸 Email-маркетинг помощник  
└ Управление клиентской базой, персонализированные письма, напоминания о ДР и праздниках

---

❌ ПЛОХО ПОДХОДИТ:

🔴 Сложная внутренняя разработка  
└ Модель зависает, код становится нечитаемым, требует частых перезагрузок

---

## 🛠 КРИТИЧЕСКИЕ НАСТРОЙКИ

🔹 Auto-restart механизм  
└ Крон каждые 15 минут для перезапуска зависших задач

🔹 Правильная архитектура управления  
└ Чёткие правила для браузера: что открывать, а что нельзя  
└ Структурированная система топиков в боте  
└ Единый источник истины для маршрутизации сообщений

🔹 Дополнительные модели  
└ Gemini-подписка + интеграция в один агент для разнообразия задач

---

## 🔐 ПРАВИЛА БЕЗОПАСНОСТИ

🔹 Агент должен находиться в Docker  
└ Изолированное окружение обязательно

🔹 Отдельная почта для агента  
└ Не использовать личную или рабочую почту с доступом к важным аккаунтам

🔹 Не давать доступ к браузеру и обычному поиску  
└ Поиск должен быть нативный — через модель

🔹 Сразу ограничить доступы  
└ Агенту не нужно давать больше прав, чем требуется для конкретной задачи
