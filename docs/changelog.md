## 2026-08-01 — Группа D: брейнсторм проведён, спек написан и согласован

- Модальный редактор файлов (`.overlay`/`.editor` в `project-workspace.html`)
  заменяется раздвижной панелью между деревом и чатом — панель раздвигает
  layout, чат сужается, но остаётся видимым и рабочим. Второй пункт
  исходной задачи («узкая колонка чата → расширяемая область») закрывается
  тем же изменением: ручной resize + сворачивание у дерева и боковой
  панели, без отдельного «авторасширения» (подтверждено пользователем).
- Решение по варианту раскладки зафиксировано интерактивным HTML-черновиком
  (Artifact, два варианта на реалистичных данных — задачник Кирика,
  drag-resize и collapse реально работают в мокапе) — пользователь
  попробовал оба вживую в браузере и выбрал вариант «панель раздвигает
  layout» вместо отклонённого «редактор разворачивается на весь центр,
  чат сворачивается в узкую полосу».
- Раскладка меняется с CSS Grid на Flexbox (переменное число видимых
  колонок проще выражать через `flex-basis`/`display`). Решены детали
  поведения: сохранение не закрывает панель (в отличие от сегодняшней
  модалки), `confirm()` при переключении файла с несохранёнными правками,
  ширины колонок и свёрнутость — в `localStorage`, глобально (не
  per-проектно, в отличие от `expandedPaths` D-014). Сознательно не
  делаются номера строк/подсветка синтаксиса, вкладки нескольких файлов,
  адаптивная вёрстка (YAGNI, вне объёма среза).
- Спек:
  [superpowers/specs/2026-08-01-workspace-layout-redesign-design.md](./superpowers/specs/2026-08-01-workspace-layout-redesign-design.md).
