# 🗓 История изменений

> Хронология того, **что уже сделано** — новое сверху.
> Каждая запись = один осмысленный шаг (фича, фикс, деплой, решение).
> Файл **только дописывается**. Подробности любого шага всегда можно
> увидеть в git: `git log --oneline`, `git show <hash>`.
>
> Пиши коротко и по-человечески: «что изменилось» и «зачем», а не
> «изменён файл X». Привязывай к датам.

## Формат записи

```
## ГГГГ-ММ-ДД — Заголовок шага
- Что сделали (по пунктам)
- Зачем / что это даёт
- Связанные решения: D-NNN (если есть)
```
