## 2026-07-24 — Параллельные задачи в Matrix: нашли и починили MATRIX_DM_AUTO_THREAD, завели docs/manual.md
- Заказчик пожаловался: несколько задач подряд в «Hermes room» сыпались
  в одну ленту, а не расходились по веткам, хотя по докам Hermes
  авто-ветки включены по умолчанию.
- Разобрали вживую на реальных скриншотах: `busy_input_mode: interrupt`
  (default) — новое сообщение, отправленное пока агент занят, не встаёт
  в очередь, а перенаправляет текущий прогон как поправку. Для реальной
  параллельной задачи нужен `/bg`.
- Отдельно нашли настоящую причину плоской ленты в исходниках
  (`plugins/platforms/matrix/adapter.py`): `MATRIX_AUTO_THREAD=true`
  (default) работает только для обычных комнат — «Hermes room» Hermes
  сам зарегистрировал как DM (свой `m.direct`-учёт, не связан с тем, как
  комнату создавали в Element), а для DM действует отдельный флаг
  `MATRIX_DM_AUTO_THREAD` с default **`false`**. Добавили
  `MATRIX_DM_AUTO_THREAD=true` в `.env`, перезапустили
  `hermes-gateway.service`.
- Побочный эффект: рестарт шлюза прервал задачу заказчика, которая была
  в процессе (torch/OCR). Проверили по логам — Hermes сам восстановил
  сессию после рестарта («Scheduled auto-resume»), ничего не потеряно.
- Заодно поймали и разобрали реальный сбой wormsoft.ru (несколько
  180-секундных таймаутов подряд на `/chat/completions`, при этом
  `/models` отвечал мгновенно) — подтвердили прямым curl-тестом в обход
  Hermes, что это внешний провайдерский сбой, не наша настройка.
  Через ~15 минут сам восстановился (проверено фоновым polling).
- Живьём проверили `/bg`: пока агент разбирал PDF в основной ветке,
  параллельная команда `/bg <вопрос про холодильник>` открыла свою
  отдельную ветку с Task ID — задачи не смешались.
- Собрали всё в новый файл **`docs/manual.md`** — практическая шпаргалка
  «как пользоваться агентом» (не архитектура, а живое общение): как
  ставить параллельные задачи, таблица слэш-команд, что означает
  сообщение про «waiting on provider», особенности этой конкретной
  установки. Ссылка добавлена в `CLAUDE.md` и `state.md` — пригодится,
  когда заказчик будет тиражировать проект друзьям.
- Связанные решения: D-005 (доп. про DM auto-thread)
