### Аккаунты на сервере
| Аккаунт | Доступ | Права | Назначение |
|---|---|---|---|
| `root` | SSH-ключ (локально: `~/.ssh/id_ed25519_hermes_vps`) | полные | администрирование/установка ПО |
| `deploy` | создана заказчиком заранее | состоит в группе `sudo`, пароль неизвестен нам | резервный админ-доступ на случай отключения root-логина по SSH; пока не используем |
| `hermes` | SSH-ключ (локально: `~/.ssh/id_ed25519_hermes_user`) | без sudo, пароль заблокирован (`passwd -l`); группа `docker` — добавить после установки Docker | под этим аккаунтом будет крутиться сам агент |

Приватные ключи живут только локально в `~/.ssh` на машине-администраторе,
в git не попадают (см. `.gitignore` и правило в `CLAUDE.md`). Паролей от
серверных аккаунтов в текстовом виде нигде нет — если понадобится реальный
пароль (например, для `deploy`), хранить в менеджере паролей, а не в репо.
