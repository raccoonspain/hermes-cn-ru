## Одним предложением

Развернуть личного AI-агента **Hermes** (open-source, NousResearch) на VPS
в РФ-зоне, с доступом через **Matrix** (а не Telegram), на китайских LLM
через RU-подписку, для трёх ролей: обучение по темам, поиск-ассистент,
IT/dev-ассистент.

## Цели и ограничения

1. Агент крутится на VPS в РФ-зоне — чтобы не мешали блокировки РКН и был
   доступ без VPN.
2. Доступ к агенту через чат — **Matrix**, а не Telegram (как обычно делают).
   1. У заказчика поднят собственный Matrix-сервер (домашний сервер, статичный
      IP и домен), можно заводить учётные записи и работать через Element
      (телефон, ПК).
3. Должна быть возможность общаться с агентом через веб-морду — на случай
   работы за чужим компьютером, где нельзя поставить Element, а для
   Matrix Web нужен VPN.
4. Модели — через RU-подписку на поставщика (wormsoft.ru), который
   предоставляет исключительно китайские модели.

## Роли и сценарии использования

### Инструменты, которыми должен пользоваться агент
- Понимание изображений (скриншот в чат → агент понимает содержимое).
- Транскрибация: ссылки на YouTube/другие видеохостинги, видео, залитые на
  VPS, голосовые сообщения в чате.
- Работа с файлами в обе стороны: нередактируемый PDF ↔ редактируемые
  Word / Excel / DXF.
- Веб-поиск через подписку Perplexity.

### Роль 1 — помощник по изучению темы («Блок знаний»)
- Заказчик заводит тему → агент создаёт под неё проект.
- Заказчик сбрасывает контекст (учебники, лекции) или просит агента найти
  материал самому.
- Агент собирает конспект, делает HTML-программу с тестами/задачами для
  самопроверки.
- По задачникам — агент делает разбор конкретных номеров в HTML
  (текст + изображения: графики, векторы, примеры).
- Темы собираются в индекс: агент сам решает, заводить новую тему или
  продолжать существующую похожую, без дублирования.

### Роль 2 — ассистент по теме («Блок поиска»)
- Заказчик задаёт тему/вопрос → агент ищет через Perplexity.
- Дальше — открытый диалог с использованием поиска и подключённых моделей.
- В процессе агент генерирует документы/схемы/таблицы в нужном формате.
- По запросу тема фиксируется в Блоке знаний для дальнейшего развития.

### Роль 3 — IT-ассистент («Блок разработки»)
- Резервный канал для написания кода и поддержки инфраструктуры, когда нет
  возможности дать доступ Claude Code / Codex к файлам.
- Темы также заводятся проектами, с архивом изученного (грабли, правила,
  документация по средам/сервисам), возможно — библиотека шаблонов.
- Заказчик присылает вопросы, куски кода, файлы; агент пишет/чинит/
  анализирует код.
- Языки: Python, JS, PHP, SQL и т.п., плюс архитектура **1С**
  (бухгалтерия и управление предприятием, зарплата и управление персоналом).
- Сетевая инфраструктура: помощь с VPN/прокси серверами.

### Сквозное требование
Есть свои VPN-серверы — агент должен уметь их использовать, чтобы работать
с видео по ссылкам YouTube (обход блокировок при обращении с РФ-адреса).

## Имеющиеся ресурсы

- Подписка Perplexity.
- Подписка на LLM-модели через RU-портал:
  - тарифы: https://ai.wormsoft.ru
  - модели: https://ai.wormsoft.ru/models
  - тариф Payed: 3 000 000 кредитов каждые 4 часа.

## Технологическая база

- **Hermes Agent** (NousResearch) — open-source, self-hosted персональный
  AI-агент с мессенджер-шлюзами, памятью, скиллами и крон-задачами.
  - Официальный репозиторий: https://github.com/NousResearch/hermes-agent
  - Официальная документация: https://hermes-agent.nousresearch.com/docs
- Вспомогательные материалы — гайды стороннего канала Futura AI
  (`source/Futura AI/`, части 1–3 + шаблоны docker-compose/.env/hooks/SOUL.md).
  Полезны для быстрых промптов и примеров конфигов, но местами устарели —
  см. предупреждение в [CLAUDE.md](../CLAUDE.md).

## Ключевые находки по возможностям Hermes (проверено по офиц. докам, 2026-07-24)

- **Matrix поддерживается нативно и полноценно**: голос, изображения, файлы,
  треды, реакции, стриминг — на уровне Telegram. Нужен отдельный
  Matrix-аккаунт под бота на своём homeserver (`MATRIX_HOMESERVER`,
  `MATRIX_ACCESS_TOKEN`), бот вступает в комнату по инвайту, есть whitelist
  пользователей/комнат, опционально E2EE. Это снимает главный
  архитектурный риск проекта.
- **Кастомные OpenAI-совместимые провайдеры** подтверждены практически —
  wormsoft.ru подключается напрямую (эндпоинт отдаёт 19 моделей).
- Есть **per-task роутинг моделей** (`auxiliary: vision / compression /
  approval` и т.п.) — можно назначать дешёвую модель на вспомогательные
  задачи и сильную только на основной диалог. Прямой рычаг оптимизации
  расхода токенов из подписки wormsoft.ru.
- **Vision** (`vision_analyze`) встроен как базовый инструмент.
- **PDF/Word/Excel** закрываются штатными скиллами: `pdf`, `docx`, `xlsx`,
  `nano-pdf`, `ocr-and-documents`. **DXF нигде не найден** — потребуется
  кастомный скилл (обёртка над ezdxf / ODA File Converter / LibreCAD).
- **YouTube** — скилл `youtube-content` (транскрипты → конспекты/посты).
  Проксирование через собственный VPN для обхода блокировок — не встроенная
  фича, это сетевая настройка на уровне VPS.
- Явной встроенной интеграции с Perplexity как отдельным search-backend'ом
  в докам не найдено; вероятный путь — подключить Perplexity как
  провайдера/модель напрямую (её sonar-модели сами делают grounded-поиск).
  Требует проверки на практике.
- 1С-специфика не найдена — ожидаемо, это база знаний/промпт-инжиниринг
  поверх агента, а не готовая фича Hermes.
- Требования к железу VPS в документации явно не указаны. Сам Hermes —
  лёгкое Python/Node-приложение, основная нагрузка уходит в облачные модели;
  сайзинг VPS будет зависеть в первую очередь от того, держим ли что-то
  локально (не планируется, раз есть подписка на модели).
